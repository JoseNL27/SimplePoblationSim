# SimplePoblationSim

A small Python simulation I made to explore how a population behaves when it reaches the limits of its available food resources.

The project was mainly an experiment with Python and simple population modelling.

## What it does

The simulation models a population over time based on food availability and consumption.

The results are stored in a text file so they can be inspected after running the simulation.
